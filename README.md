# 一周年纪念 · 给宝宝的礼物

给女朋友做的一周年礼物网页。

效果参考抖音上那条 **《生日祝福爱心全屏代码，快送给你快过生日的ta吧》（#爱心 #代码 #编程 #生日 #弹窗）**，把它改成一周年主题，并补上了视频里没有的「我们的故事」部分。

**纯静态网页，不用装任何东西，双击 `index.html` 就能看。**

---

## 一、打开后的流程

| 顺序 | 页面 | 内容 |
|---|---|---|
| ① | `index.html` | **爱心页**：几十个浅色小窗沿着心形一张一张贴上去，堆成一颗爱心；中间卡片写「一周年快乐 ♡」；贴完后点「一起吹蜡烛 ♡」 |
| ② | `cake.html` | **蛋糕页**：深色背景里的 3D 三层蛋糕 + 3 根点着的蜡烛，可以拖动转一转；点「吹蜡烛」→ 火焰依次熄灭、冒烟、礼花爆发，出现祝福大字 |
| ③ | `story.html` | **故事页**（10 个模块）：故事线章节 → 一年数据档案 → 关于她的小档案 → 点点滴滴 → 照片墙 → 一起做的小事 → 一封信 → 想对你说的话（可换一句）→ 给一年后的我们（点击展开）→ 未来清单；顶部还有「距离下一个纪念日」倒计时 |

桌面和手机都能看：爱心页横屏更好看，蛋糕页和故事页竖屏更舒服。

## 二、改成你们自己的（只需要改 `js/data.js`）

打开 `js/data.js`，每一项都有中文注释，改完保存、刷新浏览器即可。

| 字段 | 作用 |
|---|---|
| `to` / `from` | 她的称呼、你的署名（信末签名优先用 `sign`，`sign` 留空时用 `from`） |
| `togetherDate` | 在一起的日期 `YYYY-MM-DD`，天数自动计算（三页都会用） |
| `years` | 第几个纪念日（蛋糕页祝福大字用） |
| `mainMessage` | 爱心页中间卡片、入口卡、蛋糕巧克力牌、故事页标题上的主文案 |
| `wishes` | 每个小弹窗上的一句话，建议 28~36 条、每条 2~8 个字 |
| `chapters` | 故事线章节：`stage` 阶段（相遇/心动/在一起…）+ `date` + `title` + `text` + 可选 `photo`，建议 5~8 章 |
| `numbers` | 一年数据档案：`value` + `unit` + `label`（365 天 / 52 次 / ∞ 想你…） |
| `aboutHer` | 关于她的小档案：`q` 问题 + `a` 答案（爱吃、最怕、口头禅…） |
| `moments` | 卡片「我们的点点滴滴」 |
| `photos` | 照片墙，`file` 写文件名，`caption` 是照片下面的小字 |
| `smallThings` | 一起做的小事清单：`text` + `done`（true 显示「已做过」，false 显示「想做」） |
| `letter` | 「写给你的一封信」，一段一条 |
| `loveNotes` | 「想对你说的话」，页面点「换一句」随机切换 |
| `futureLetter` | 「给一年后的我们」：`title` + `text`，默认封着，点击展开 |
| `promise` | 「以后想和她一起做的事」 |
| `countdowns` | 顶部倒计时数组：`label` + `date`（`YYYY-MM-DD`，日期过了自动滚到下一年，可放多个） |
| `sign` | 信末尾的署名（想用 `from` 就把它留空） |

> **`data.js` 已经按采访到的真实故事填好了**（在一起日期 2025-11-25、故事线 13 章、一封信、情话、未来信、小事清单、倒计时等）。有些早期事件的日期记不清，用的是「2025 年 11 月」这种大概时间，你知道具体日子可以直接改成精确日期。

## 三、放照片 / 音乐

**照片**：把照片放进 `assets/photos/`，文件名和 `data.js` 里 `photos[].file` 对上即可：

```
assets/photos/photo-1.jpg
assets/photos/photo-2.jpg
...
```

- 建议 3:4 竖图、单张压到 1MB 以内（手机原图太大，加载会慢）。
- 没放照片时，照片墙会自动显示粉色占位卡片，不影响整体效果。
- 加照片：在 `photos` 数组里复制一行改成新文件名；删照片就删掉那一行。

**音乐**：已经内置了一首免版权的背景音乐——**Romantic Piano（AtlasAudio，Pixabay 免费授权）**，放在 `assets/music/bgm.mp3`。故事页右下角有个 ♪ 按钮，点一下开始播放，再点暂停。

- 想换歌：直接把你的 mp3 命名成 `bgm.mp3` 覆盖掉这个文件就行（建议 2~4MB）。
- 想用《我是真的爱上你》这类版权歌曲：**私人自用没问题**，但别公开分享或发布，会有版权风险。
- 没有音乐文件时按钮会自动隐藏，不影响页面。

## 四、怎么发给她

| 方式 | 做法 | 适合 |
|---|---|---|
| **A. 静态托管（推荐）** | 把整个文件夹拖到 GitHub Pages / Vercel / Netlify，把生成的链接发给她 | 手机微信里直接打开，最稳 |
| **B. 局域网** | 在文件夹里运行 `python -m http.server 8080` 或 `npx serve`，手机连同一个 WiFi，访问 `http://电脑IP:8080` | 不想部署，只在家里一起看 |
| C. 电脑本地预览 | 自己双击 `index.html` 先看效果 | 仅电脑，别用这种方式发她 |

⚠️ 三个页面、照片、音乐都是**相对路径**，所以：

- 托管 / 局域网：把**整个文件夹**上传或共享，不要只传 `index.html`。
- 微信里**不要**直接发 zip 或 HTML 附件（iPhone 的文件 App / 微信内置打开本地 HTML 会缺资源、不跑 JS），发**链接**最保险。
- 如果一定要把本地文件发给她，只能让她在**电脑**上解压双击打开。

## 六、想再改点什么

- **爱心页配色**：`index.html` 里 `PALETTE` 数组（8 组马卡龙色，每组「浅色 / 深色 / 文字色」）。
- **背景手写体**：`index.html` 里 `.bg-script` 两个 div（「一周年」和「Happy Anniversary」），文案和大小都能改。
- **蛋糕配色 / 蜡烛数量**：`js/cake.js` 顶部的 `CANDLE_DEFS`、`SPRINKLE_COLORS`、各层蛋糕体颜色。
- **故事页模块**：想加/删模块，改 `js/story.js` 里的 `buildStory()`；样式复用 `css/story.css` 里的 `.tl-card` / `.moment` / `.letter` 等类。
- **只看爱心不炸开**：`index.html?preview=1`（预览模式）。
- **强制刷新**：`Ctrl + F5`；手机清一下缓存。

## 八、已验证 / 未验证

- ✅ 已验证：Chrome 无头浏览器在 390×844（手机竖屏）、1280×800（桌面）下，三页完整点击流（爱心 → 入口卡 → 蛋糕 → 吹蜡烛 → 故事 → 页脚按钮）全走通，0 个 JS 异常，365 天计算正确，无死链；WebGL 不可用时蛋糕页会显示降级卡片（可以直接看祝福）；照片缺图自动变粉色占位。
